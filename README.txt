ORBITWISE: MISSION ARCHITECT — V4 COMPLETE

HOW TO RUN
1. Extract this ZIP into a new folder.
2. Keep index.html, style.css, and app.js together.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. No Python, Node.js, server, or installation is required.

V4 FEATURES
- Interactive mission-control dashboard with animated Mars scene.
- Solar array / RTG-style power-system choice.
- Mission priority, science instruments, and mission duration controls.
- Live illustrative budget, power reserve, science, risk, and readiness calculations.
- Mission Doctor diagnosis and recommendations.
- Interactive contingency events with choices and consequences.
- Compare your live design against a robust alternative.
- NEW: launch-vehicle capacity selection and spacecraft mass estimate.
- NEW: Mars destination, orbit/operations profile, and communications choices.
- NEW: constraint-fit warnings when modeled spacecraft mass exceeds the selected launch capacity.
- Export a mission report including engineering constraints and decision history.
- General educational Mars facts.

IMPORTANT SCIENTIFIC LIMITATIONS
This is an educational browser prototype. Mission costs, spacecraft mass, launch capacities, communications coverage, power, risk, science, readiness, and success estimates are simplified illustrative values. They are not official NASA specifications, engineering models, orbital mechanics calculations, or real flight predictions. The app does not currently fetch live NASA API data. Do not describe the estimates as NASA data. Google Fonts are optional; fallback fonts work offline.
